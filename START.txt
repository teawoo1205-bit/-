황혼의 성채 — 2~4인 협동

방장 또는 서버 운영자
1. 이 ZIP 전체를 한 폴더에 압축 해제합니다.
2. Python 3.10 이상이 설치된 컴퓨터에서 해당 폴더를 열고 두 명령을 순서대로 실행합니다.
   python -m pip install -r requirements.txt
   python server.py
3. 같은 Wi-Fi의 친구는 브라우저에서 http://방장컴퓨터의로컬IP:10000 을 엽니다.
   방장 컴퓨터에서는 http://localhost:10000 으로 열 수 있습니다.
   다른 네트워크에서 함께하려면 이 서버를 배포하고 같은 배포 주소를 엽니다.
   기존 호스팅 서버는 이 ZIP의 게임 파일, server.py 및 requirements.txt로 업데이트합니다.
4. 게임 시작 → 친구와 협동 → 일반 모드 또는 보스레이드 방 만들기를 누릅니다.
   친구는 같은 주소에서 6자리 방 코드로 참가합니다. 각자 캐릭터의 능력을 살펴보고 선택을 누릅니다. 옷걸이로 스킨을 고른 뒤 방장이 시작합니다.
